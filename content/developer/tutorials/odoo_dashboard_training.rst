================================================
Training: Membuat Dashboard Odoo dengan Chart.js
================================================

.. toctree::
    :titlesonly:
    :glob:

    odoo_dashboard_training/*

Selamat datang di Training **Membuat Dashboard Odoo dengan Chart.js**! Training ini dirancang
khusus untuk developer Odoo yang ingin membangun tampilan dashboard interaktif menggunakan
JavaScript framework Odoo (OWL) dan library Chart.js.

Dalam training ini, kita akan membangun sebuah aplikasi Real Estate dari awal hingga menampilkan
Dashboard yang informatif dan interaktif. Setiap bab saling berkaitan dan harus diikuti secara
berurutan.

Tujuan Training
===============

Setelah menyelesaikan training ini, peserta diharapkan mampu:

- Menjalankan lingkungan pengembangan Odoo menggunakan Docker
- Mengkonfigurasi Visual Studio Code untuk pengembangan modul Odoo kustom
- Membuat modul Odoo dasar bertema Real Estate
- Membangun Dashboard interaktif menggunakan OWL Component dan Chart.js
- Membuat endpoint backend yang menyediakan data untuk Dashboard
- Mengimplementasikan fitur filter pada Dashboard

Prasyarat
=========

Sebelum memulai training ini, pastikan Anda telah memahami:

- Dasar-dasar Python
- Konsep dasar HTML, CSS, dan JavaScript
- Dasar-dasar penggunaan terminal/command line
- Konsep dasar OOP (Object-Oriented Programming)

.. note::

   Jika Anda belum familiar dengan framework Odoo, disarankan untuk mempelajari
   :doc:`Getting Started Tutorial </developer/tutorials/getting_started>` terlebih dahulu.
